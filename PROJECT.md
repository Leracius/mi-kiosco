# Mi Kiosco

Aplicación para consultar precios de productos en un kiosco.

## Criterios del proyecto

1. Usar el [diseño de Figma](https://www.figma.com/design/iwsSx3XchUbCuJBBrCzjOZ/mi-kiosco?t=SUvk3d5J9JQxl2tO-0) como referencia visual principal.
2. Mantener una arquitectura clara y mantenible con React, Vite y TypeScript.
3. Implementar las funcionalidades de forma progresiva.
4. Evitar complejidad innecesaria.
5. Explicar las decisiones técnicas relevantes para facilitar el aprendizaje.

Aplicar buenas prácticas generales de UX/UI y accesibilidad, sin requisitos adicionales basados en la edad.

Respetar el diseño de las pantallas. Si aparece un problema de usabilidad o implementación, explicarlo antes de realizar cambios al diseño. Cualquier rediseño debe acordarse previamente.
